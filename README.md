# I BANK — demo prototype

Bu loyiha I BANK moliyaviy boshqaruv prototipi. Hozircha ma'lumotlar brauzer xotirasiga emas, React state'iga demo sifatida saqlanadi; sahifa yangilanganda demo holat qaytadi.

## Ishga tushirish
1. Node.js 18+ o'rnating.
2. Shu papkada terminal oching.
3. `npm install`
4. `npm run dev`
5. Terminal ko'rsatgan `http://localhost:...` manzilni brauzerda oching.

## Keyingi bosqich
Haqiqiy doimiy ma'lumotlar uchun Supabase/PostgreSQL backend, autentifikatsiya, RLS va audit log qo'shilishi kerak. Haqiqiy kredit/valyuta xizmatini ishga tushirishdan oldin tegishli litsenziya va qonuniy talablar tekshiriladi.
